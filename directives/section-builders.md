# Section Builders

This directive describes standard report section builders.

## Builders list
- **HeaderSectionBuilder**: Concat branding logos and company titles.
- **SummarySectionBuilder**: Aggregates row values (averages, totals).
- **MetricsSectionBuilder**: Details report rows data up to `maxRows`.
- **ForecastSectionBuilder**: Integrates with `ForecastService` to map predictive models.
- **FooterSectionBuilder**: Concat signature options and localized date/time values.
